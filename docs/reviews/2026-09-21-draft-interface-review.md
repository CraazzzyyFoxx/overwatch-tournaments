# Полный обзор интерфейса страницы драфта

Дата анализа: 2026-09-21. Режим: **full** (`better-interface`).

## Рекомендация

Превратить страницу в спокойную комнату драфта, а не в ещё один hero-экран: однотонный графитовый фон, компактный header, один заметный блок текущего хода и полноценный список игроков для зрителя.

Исходники в рамках анализа не редактировались. Ниже — проверенные проблемы и предлагаемое направление. Реализация дизайна требует отдельного согласования.

## Scope and Coverage

**Режим: full.** Проверена публичная страница `/draft/95`: реальный завершённый драфт на 14 команд и 70 игроков; live, pause, loading, empty и error — через временные состояния в браузере, без изменения серверных данных.

Стек: Next.js 16, React 19, Tailwind 4, CSS Modules, Radix/shadcn, токены `--aqt-*`, Inter и Onest. Капитанский интерфейс проверен по исходникам, без выполнения пиков.

## Предлагаемый дизайн

### 1. Фон: убрать декорацию, оставить глубину

Сейчас сетка есть **дважды**: 64×64 на странице и 48×48 внутри `HeroFrame`, плюс два источника свечения.

Предлагается:

- сплошной `--aqt-bg` на странице;
- `--aqt-card` для содержательных панелей;
- спокойные границы вместо свечения вокруг обычных блоков;
- цветовой акцент — на текущем ходе и выбранной команде;
- без фонового арта, новой палитры и новых шрифтов.

Это локальная переработка комнаты драфта: оформление hero на остальных страницах не нужно менять.

### 2. Header: идентификация сверху, действие ниже

**Первая строка:** назад к турниру → название → статус. Справа — зрители и компактный статус соединения.

**Отдельная полоса хода:**

> Пик 15 из 56 · Сейчас выбирает ItsSoldeek · Далее TOP50RUGENJI · **00:56**

Из постоянного header убрать дату, формат, размер состава и россыпь аватаров капитанов. Эти сведения доступны через «О драфте», а присутствие капитана логичнее показывать возле его команды.

После завершения:

- убрать «Ходит сейчас —»;
- заменить «Пул игроков: 0» на ясные итоги;
- не сохранять визуальный акцент на уже несуществующем ходе.

### 3. Игроки для зрителей: полноценный просмотр, не выключенная панель капитана

**Десктоп:** основная область «Составы / Игроки», справа — компактная очередь.

**Телефон:** три доступные вкладки «Игроки / Составы / Очередь».

В списке игроков:

- поиск по нику;
- фильтр по роли;
- сортировка по рейтингу или имени;
- статусы **«Доступен» / «Выбран — команда»**;
- переключение **«Доступные / Все»**;
- просмотр публичных данных игрока без ухода со страницы.

Важно: не показывать зрителю неактивные «Подтвердить пик», проверку допустимости пика и инструкции капитана.

**Новый API для самого списка не нужен:** общий снимок уже содержит `board.players`. Можно переиспользовать существующие фильтры и представление игроков.

### Ещё идеи — по приоритету

| Приоритет | Идея | Польза |
|---|---|---|
| **Следом** | **Последний пик:** «Команда X выбрала Y · саппорт» | Зритель сразу понимает, что изменилось |
| **Следом** | В очереди сначала текущий и ближайшие 2–3 хода; история раскрывается отдельно | Не нужно искать активный пик среди уже завершённых |
| **Следом** | **Следить за командой** — локальное выделение выбранной команды | Удобнее наблюдать за большим драфтом |
| **Позже** | Сравнение двух игроков по ролям, рейтингам и героям | Полезно зрителям и комментаторам; без выдуманного «общего балла силы» |
| **Позже** | Режим трансляции: крупнее имена и таймер, меньше служебных элементов | Отдельная композиция для OBS, если страницу действительно выводят в эфир |

## Verification

### Проверено

- `bun run dev --hostname 127.0.0.1` → локальная страница `/draft/95` открылась с реальными данными.
- Изменение viewport: **1440 → 768 → 390 → 320 px** → измерены header, положение очереди и обрезание таблиц.
- Переходы клавишей `Tab` → у ссылок возврата и навигации виден фокус.
- Временные состояния в клиентском кеше: **live, paused, empty, error, loading** → проверены отображение таймера, сообщения, кнопка повтора и skeleton. Серверные данные не менялись.
- `prefers-reduced-motion: reduce` → анимации skeleton и live-индикатора отключились.
- Цвет фона взят из PNG; альфа-композиция текста и расчёт WCAG дали **3,20:1**.

### Not verified

- Работа со скринридером и реальный браузерный zoom 200%.
- Выполнение пика авторизованным капитаном.
- Полный realtime/chat: локальная версия показывала переподключение и `Not Found`. Это ограничение проверки интеграции, не основание для дизайн-замечания.

## Приоритет реализации

Спокойный фон → компактный header и полоса хода → игроки для зрителей.

Одновременно стоит устранить обрезание таблиц и слабый контраст. Остальные идеи — отдельными улучшениями после этой основы.
