A mix is a custom game run by somebody in your community: the host gathers a lobby, the platform splits everyone into two even teams and keeps the win record. This page covers how to get into one, what the participation statuses mean and how results are counted.

## Where to find mixes

The **Mixes** section in the site menu shows the selected community's mixes: "Open lineups and follow your community's results." You can watch without signing in.

The list is split into **Open** and **History**. Each row shows the name, who it is **Hosted by**, and the state of the mix:

| Status | What it means |
| --- | --- |
| **Preparing** | The host is still gathering the lobby |
| **Teams ready** | The split is done, the game can start |
| **Completed** | The mix is closed, its results are in the history |
| **Cancelled** | The mix never happened |

## Getting into a mix

You cannot sign yourself up: the host builds the lineup. They add players from the community's member list, so you need to be in that community and ask the host to add you.

Your roles and rank come from the community's own data, so there is no entry form to fill in.

## The three participation statuses

Every player the host added sits in one of three columns. The labels on that screen are in English:

| Status | What it means |
| --- | --- |
| **Must play** | A seat is guaranteed: this player will be in the lineup |
| **In the pool** | Ordinary participation — the player goes into the split and may play or sit out |
| **Benched** | Sitting out: the player stays in the mix and keeps their roles and rank, but is not in the current lineup |

The host moves players between the columns in one drag — handy when you arrive late or step away for a break.

## Who sits this one out

A lobby holds ten people. If more than that are in the split, the extras are benched automatically, and fair rotation decides who — not the host by hand.

The order is simple: whoever has sat out the longest run goes in first, then whoever has played the shortest run, then whoever has the fewest games in this mix. Players marked **Must play** are always seated. When there is no game history yet, or everyone fits into the lobby anyway, nobody is singled out.

The host sees rotation hints — who is owed a seat and who should rest — and can apply them in one press.

## How the teams are built

The platform splits the lobby so the ranks come out even and as many people as possible get a role they want. Those two goals conflict, so the host chooses what matters more: tighter rank balance or more comfortable roles.

One run usually offers several possible splits. Which one is on screen is shared: the host and every viewer read the same lineup. The **Next map** can be shown there too, once the host has rolled or chosen it.

If the community has a Discord channel configured, the host can post the finished lineup there in one press.

## Results

After each game the host marks the winner (or a draw) — the game goes straight into the mix's history and you play on. A mistaken entry can be undone.

The mixes page also has a **Leaders by wins** table. It covers all time, the last 30 days or the last 7 days, requires a minimum number of matches in that period, and is "ranked by wins, then win rate, then matches played."

<Callout>
If the host turned on points per win, a mix result nudges your rank in that host's own private rank book. That book is used only in their mixes — it does not change your rank in the community or in tournaments.
</Callout>

## If you host mixes yourself

Host settings live in your account, not in the game: the **Mixes** tab in account settings — "How your pickup mixes are set up and balanced. Every mix you host uses these, so they are set once here instead of on every game." That is where rank balance versus role comfort, line importance, the number of balance options per run and points per win are configured.

For the full picture, see [Mixes for hosts](/docs/organizers/mixes).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| "No mixes yet" | Nobody in this community has created one |
| You are not in the lineup | Ask the host to add you — there is no self sign-up |
| You were benched | That is the rotation, not a verdict on you: you get priority next game |
| Your role in the lineup is not the one you wanted | Tell the host — roles and ranks are edited on your player card |
