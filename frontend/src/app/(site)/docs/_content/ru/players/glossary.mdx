Короткий словарь слов, которые встречаются на сайте. В скобках — английский термин: он же используется в английской версии сайта.

## Сообщество и аккаунт

| Термин | Что это значит |
| --- | --- |
| Воркспейс (workspace) | Сайт одного сообщества: свои турниры, свои ранги и достижения. Переключается кнопкой **Сменить воркспейс** в шапке. |
| Профиль игрока | Ваша игровая личность: BattleTag, история матчей, статистика, достижения. Он один на аккаунт. |
| Профиль без аккаунта | Профиль игрока, который сообщество знает по логам матчей или по импорту, но за которым никто не вошёл на сайт. Он участвует в составах и статистике, пока владелец не привяжет его к своему аккаунту. |
| BattleTag | Ваш ник в Overwatch вида «имя#1234». Не переводится. |
| Смурф | Дополнительный аккаунт Overwatch того же игрока. В заявке их перечисляют отдельно. |
| Привязанный аккаунт | Discord, Battle.net или Twitch, подтверждённый через OAuth. Нужен для входа, уведомлений и проверки требований допуска. |

## Турнир

| Термин | Что это значит |
| --- | --- |
| Турнир (tournament) | Соревнование внутри одного сообщества: свои заявки, этапы и таблицы. |
| Фаза (phase) | Где турнир находится по жизненному циклу: анонс, регистрация, чек-ин, драфт, игра, завершён. От фазы зависит, что можно делать прямо сейчас. |
| Расписание фаз (schedule) | Даты и время, когда открывается и закрывается каждая фаза. |
| Этап (stage) | Соревновательная часть турнира — групповой этап или плей-офф. Не путать с фазой: фаза про жизненный цикл, этап про игру. |
| Групповой этап (group stage) | Этап, где команды играют внутри групп, а дальше проходят лучшие. |
| Круговой (round-robin) | Формат, где каждая команда играет с каждой. |
| Швейцарка (swiss) | Формат на фиксированное число туров, где соперника подбирают по текущему количеству очков. |
| Плей-офф (playoff) | Этап на вылет. |
| Сетка (bracket) | Дерево матчей на вылет: кто с кем играет и куда попадает победитель. Бывает с одним или двумя поражениями. |
| Таблица (standings) | Таблица результатов этапа: победы, поражения, очки, место. |
| Посев (seed) | Порядковый номер команды на входе в этап. Влияет на пары в сетке и на то, кто первым банит карту. |
| Тай-брейки (tiebreakers) | Правила, которые разводят команды с одинаковым количеством очков. |
| Бухгольц (Buchholz) | Тай-брейк: сумма очков соперников, с которыми вы играли. Чем сильнее были соперники, тем он выше. |
| Личные встречи (head-to-head) | Тай-брейк: кто кого обыграл при личной встрече. |
| Разница карт (score differential) | Тай-брейк: выигранные карты минус проигранные. |

## Матчи и карты

| Термин | Что это значит |
| --- | --- |
| Встреча (encounter) | Одна пара команд: вся серия карт между ними. |
| Матч (match) | Одна сыгранная карта. Статистика игроков считается по матчам. |
| Пул карт (map pool) | Набор карт, из которого выбирают карты серии. |
| Кандидат (candidate) | Карта или герой в пуле, которого можно забанить или выбрать. |
| Пик-бан (pick-ban) | Порядок ходов, которым стороны по очереди убирают и выбирают кандидатов: бан, пик, защита. Бывает по картам и по героям. |
| Слот (slot) | Одна карта серии. У слота может быть свой набор кандидатов. |
| Резервная карта (reserve map) | Карта, которую регламент оставляет на случай ничьей. |
| Репорт (report) | Результат, который капитан отправляет после игры. Совпали репорты обеих сторон — результат подтверждён, разошлись — оспорен. |
| Оспорен (disputed) | Стороны прислали разные результаты; решение принимает организатор. |
| Логи матча (match logs) | Файлы логов Overwatch, которые организатор загружает после игры. Из них берётся вся статистика по игрокам. |

## Заявки и составы

| Термин | Что это значит |
| --- | --- |
| Регистрация (registration) | Ваша заявка на турнир: роли, топ-герои, аккаунты и ответы на вопросы организатора. |
| Чек-ин (check-in) | Подтверждение в отведённое окно, что вы действительно будете играть. |
| Можно позвать (on call) | Отметка в заявке: вы играете как обычно, но не против, чтобы вас позвали, если кто-то вылетит. |
| Допуск (admission) | Проверка требований организатора перед турниром: открытый профиль карьеры Overwatch и подписка. |
| Ростер (roster) | Состав команды: кто на каких слотах играет. |
| Слот состава | Одно место в составе под конкретную роль или под флекс. |
| Запасной (substitute) | Игрок сверх основного состава, который выходит вместо другого. |
| Капитан (captain) | Игрок, который собирает команду, отправляет приглашения и отвечает за пик-бан и репорт результата. |
| Приглашение (invite) | Предложение занять слот в команде: именное или ссылкой с ограниченным сроком. |
| Балансировщик (balancer) | Автоматическая сборка команд: он разводит сильных игроков по разным командам и старается дать каждому желаемую роль. |
| Драфт (draft) | Живая альтернатива балансировщику: капитаны по очереди выбирают игроков, на каждый ход есть таймер. |
| Роли | Танк, Дамаг, Саппорт. Флекс означает, что вам всё равно, на какой роли играть. |

## Скримы и миксы

| Термин | Что это значит |
| --- | --- |
| Скрим (scrim) | Тренировочная встреча вне турнира: комната с вето карт, банами героев и счётом по картам. Соперник заходит по ссылке. |
| Микс (mix) | Кастомная игра сообщества: хост собирает пул игроков, делит на две команды и записывает результат. |
| Скамейка (bench) | Игроки микса, которые в этой игре не играют. Ротация следит, чтобы сидели по очереди. |

## Ранги и статистика

| Термин | Что это значит |
| --- | --- |
| Ранг (rank) | Число, которое описывает силу игрока на роли. На турнире сначала берётся ранг из заявки, затем ранг сообщества, затем ранг из Overwatch. |
| SR | Числовое значение ранга Overwatch. Не переводится. |
| Дивизион (division) | Диапазон рангов: удобная «полка», к которой относят игрока. |
| Оценка MVP (MVP rating) | Оценка вклада игрока в матч относительно других игроков той же роли. На ней основаны MVP-достижения. |
| Тайм на героях (playtime) | Доля матча, которую игрок провёл на конкретном герое. |
| Достижение (achievement) | Значок за выполненное условие. Часть считается автоматически по данным матчей, часть организатор выдаёт вручную. |
| История рангов (rank history) | График ранга Overwatch по привязанному BattleTag. |
