Editorial Tactical

A dark, broadcast-grade system for OWT — an independent community platform for Overwatch tournament history and player statistics. Premium editorial layout — air, hairline rules, big mixed-case headlines — carrying a mission-control voice: faint coordinate grid, monospace labels, oversized grotesk numbers. Multi-tenant / white-label: never hardcode brand strings, colours or logos.

01 · Air over boxes

Group with whitespace and hairlines first; a framed card is for dense data only.

02 · Numbers are telemetry

Statistics in grotesk + mono, tabular figures, like a broadcast stat overlay.

03 · Meaning over decoration

Colour and the role spectrum encode data — never ornament it. One teal leads.

Foundations

Content & voice

Flat, factual, engineer-adjacent. The product states what is true and what it cannot know — no hype, no exclamation marks, no second-person coaching.

Casing & person

Casing

Mixed case everywhere, including headings — condensed all-caps display type is rejected. Uppercase is reserved for mono labels (TOURNAMENTS) and short card titles (Onest 14/700, 0.04em tracking).

Person

Mostly impersonal. Labels are nouns ("Tournaments"), actions are bare imperatives ("Browse tournaments"). "You/your" only where the row is literally the reader's own. "We" only in failure copy: "We could not load it."

Honesty rules are content rules

  • There is no SR/MMR in OWT — never invent one in a stat or an achievement.
  • Encounter ⊃ Matches. An encounter is a series against one opponent (3–1); its matches are maps. Never label an encounter with a single map's name.
  • Mix tournaments — a player has no standing team; a team is only meaningful inside a tournament.
  • No seasons — only tournaments and periods.
  • Low-sample gate — percentiles and vs-average hide below 10 games: em dash + title explaining the rule + a LOW SAMPLE badge.
  • One term per metric, glossary in a title on first use — Closeness, never "Proximity".

Failure, empty & filtered-empty are distinct

error

"We could not load it", with Retry. Never render empty on a failed request — that is a lie about the data.

empty / filtered-empty

"Nothing here yet" vs. "Your filters exclude everything", with a Clear filters action.

Numbers, dates, emoji & bilingual

Locale-formatted via next-intl (default ru: 1 557, not 1,557). Relative dates read 2d ago with the absolute date in title — bare 2D is banned, it collides with the Draw letter. Emoji and bare glyph arrows as icons are anti-patterns (screen readers read them literally); the two typographic exceptions are the → in "View all →" and the ‹ › pagination chevrons, both aria-hidden. Every string ships EN + RU, with RU written, not translated — Onest was chosen over Space Grotesk specifically because "Grand Final" and its Cyrillic equivalent must share plasticity.

The :root-vs-<body> font trap — found & fixed upstream

Until a recent pass this stack did not render: globals.css aliased the next/font variables from :root, while layout.tsx mounted the fonts' .variable classes on <body>. A custom property resolves where it is declared, so at :root there was no font variable to resolve — and a failed var() poisons the whole declaration, so the literal fallback next to it never applied either. All 73 mono/display references in globals.css silently rendered in Inter. Fixed by mounting the classes on <html> instead (app/layout.tsx:115).

The ramp has no 6px or 10px step by design — the handful of components that need 6/10px stay literal rather than snap 33–50%. Semantic aliases: --aqt-card-pad-x/y, --aqt-row-pad-y, --aqt-hero-pad-x/y, --aqt-section-gap.

Container — verified 1720px, specified 1400px

The shipped app container is --aqt-screen-3xl: 1720px (screen-3xl in tailwind.config.ts, applied in the (site) layout — not the root layout) with px-4 / md:px-6 / xl:px-10 gutters. The design book's narrower 1400px reading measure (--aqt-content-max) is specified, not shipped — it appears nowhere in tailwind.config.ts or src. Sticky header is 56px; in-page sticky rails offset by 88px.

Shadows — downward-diffuse only

shadow-card on cards, shadow-panel on floating panels. No inner shadows, no glows except the single teal hero wash and rarity halos.

Motion

0.15s hover/colour, 0.18s tile lift, 0.2s accordion height. Plain ease/ease-out — no bounce, no spring, no entrance animation on page content. Exactly one loop in the CSS itself: the 2s aqtPulse live-dot opacity. Honors prefers-reduced-motion.

Blur — chrome-only by rule, contradicted in practice

The rule: blur is reserved for chrome — the sticky header (blur(24px)) and small pills over artwork (blur(4px)). Content surfaces stay solid. The divergence: backdrop-filter/backdrop-blur occurs 43 times across 25 files upstream — sheets, dialogs, tooltips, dropdowns, sticky toolbars. Read "chrome-only" as this book's constraint, not a description of the shipped app.

Hover, press & focus

Hover changes colour/background only, never size or layout. Rows → overlay-2, chips → overlay-3. The one sanctioned transform is a −2/−3px translateY lift on standalone tiles. No shrink-on-press. Focus is loud and universal: a 2px teal :focus-visible outline on every interactive element, including table rows — every hover popover must also open on focus and tap.

DivisionsVerified

Divisions render as icons only — never a text label on display surfaces. The emblem encodes tier + sub-tier; the name lives in alt (not just title — title tooltips are unreachable by touch/keyboard). Icons come from the workspace division grid so a community can swap the entire set.

Foundations

IconographyVerified

Icon set — lucide-react

Used everywhere, always size-4/16px at currentColor, always aria-hidden next to real text or aria-labeled when alone. A CDN dependency, not a vendored asset.

Brand-owned art

Logo, brand-mark, favicon, role glyphs (PlayerRoleIcon), division crests, hero portraits, achievement badge art, Discord/Twitch/Boosty marks — all raster/vector copied into the app, never redrawn from scratch.

Role marking rules: icon + mono label only in a Role split; icon only in tables and rows (name in alt/aria-label); text only in meta lines ("Tank main"). Division is always icon-only on display surfaces. Emoji and bare unicode glyphs as icons: never.

Divergences

Where the shipped app and this book disagree, named inline instead of averaged away.

Blur. Book says chrome-only; backdrop-filter appears 43× across 25 files upstream (sheets, dialogs, tooltips, one page with ten on its own).

Container. Book's §7 measure is 1400px; the shipped container is 1720px (screen-3xl).

Animation. This book's CSS declares one @keyframes; Tailwind animate-* utilities appear 219× across 116 files upstream.

Font trap.Fixed See Typography above: next/font classes now mount on <html>, not <body>.

Uppercase display bug.Fixed globals.css forced text-transform:uppercase on the 52px display blocks, directly against the Casing rule and the book's "never condensed-caps". Both are mixed-case now.

Never colour-only. W/L map squares carry letters; result chips always carry W/L/D letterforms — colour reinforces, never carries the difference alone.

One token source, not two families. Upstream keeps --aqt-* complete colours and bare shadcn HSL triplets as parallel sets — aliasing a shadcn name inside a scope can turn hsl(var(--card)) into hsl(hsl(…)) and silently render a subtree transparent. This book declares each value once as a triplet, exposed twice, so that failure mode cannot be expressed.

Apply

Tokens & code

The real --aqt-* triplet pattern — declare once, expose as a complete colour and as a Tailwind-wrappable bare triplet.

/* globals.css — single source of truth, real names */
:root {
  /* bare triplet — the one declaration */
  --aqt-h-teal: 172 70% 49%;
  /* exposed as a complete colour … */
  --aqt-teal: hsl(var(--aqt-h-teal));
  /* … and as a bare triplet the shadcn layer wraps itself */
  --primary: var(--aqt-h-teal); /* Tailwind: hsl(var(--primary)) */
}
/* ground */
:root {
  --aqt-bg:hsl(220 21% 5%); --aqt-bg-2:hsl(220 22% 7%);
  --aqt-card:hsl(220 22% 8%); --aqt-card-2:hsl(222 24% 11%);
  --aqt-border:hsl(219 19% 15%); --aqt-border-2:hsl(217 17% 21%); --aqt-border-3:hsl(216 16% 26%);
}

Full token catalogue: frontend/src/app/globals.css (shipped) — this book cross-references it rather than re-typing it, so the two cannot drift.
